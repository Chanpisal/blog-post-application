# Blog Post Application

A simple web-based blog application that lets users create, edit, and delete blog posts. Each post has a title and content, and the application starts with some example posts.

## Features

- Add a new blog post
- Edit the blog post title
- Edit the blog post content
- Delete a blog post
- Start with initial blog posts
- Responsive layout for smaller screens
- Simple and clean user interface
